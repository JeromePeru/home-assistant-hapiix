# Hapiix pour Home Assistant

Intégration communautaire permettant de consulter les portes, les membres et les
messages d'un compte Hapiix, puis d'envoyer une demande d'ouverture depuis Home
Assistant.

Après l'installation, redémarrez Home Assistant puis ajoutez **Hapiix** depuis
**Paramètres → Appareils et services**.

> Une pression sur une entité de porte déclenche une véritable demande d'ouverture.
> Protégez les cartes correspondantes avec une confirmation.
