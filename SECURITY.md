# Sécurité

Cette intégration pilote des accès physiques. Ne publiez jamais de code reçu par
e-mail, de jeton Hapiix, de sauvegarde Home Assistant ou de fichier situé dans
`/config/.storage`.

Pour signaler une vulnérabilité, contactez le mainteneur en privé depuis son profil
GitHub avant d'ouvrir une issue publique. Décrivez le problème sans inclure de
jeton, d'adresse personnelle, de nom d'occupant ou d'identifiant de porte réel.

Conservez la validation TLS active, limitez l'accès au dashboard et utilisez une
confirmation pour chaque action d'ouverture.
